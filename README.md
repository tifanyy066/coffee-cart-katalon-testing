# Coffee Cart Web Testing — Katalon Studio

## 1. Deskripsi Proyek
Proyek ini merupakan pengujian fungsional pada website Coffee Cart (https://coffee-cart.app/) menggunakan Katalon Studio. Pengujian dilakukan untuk memeriksa fungsi pemilihan produk, keranjang belanja, checkout, dan validasi input.

## 2. Tools yang Digunakan
- Katalon Studio 11.6.0
- Google Chrome
- Website: https://coffee-cart.app/

## 3. Daftar Test Case
Proyek ini memiliki 10 test case:
1. TC-01 — Pemilihan Produk
2. TC-02 — Menambahkan Keranjang
3. TC-03 — Menambah Dua Produk
4. TC-04 — Menambah Produk yang Sama
5. TC-05 — Checkout Pesanan
6. TC-06 — Hapus Produk dari Keranjang
7. TC-07 — Mengurangi Jumlah Produk
8. TC-08 — Kembali ke Menu
9. TC-09 — Checkout Tanpa Mengisi Nama
10. TC-10 — Mengisi Email Tidak Valid

## 4. Cara Menjalankan Pengujian
1. Ekstrak ZIP proyek.
2. Buka Katalon Studio.
3. Buka proyek Katalon yang telah diekstrak.
4. Buka folder Test Suites.
5. Pilih Test Suite yang berisi TC-01 sampai TC-10.
6. Klik Run dan pilih browser Google Chrome.
7. Periksa hasil pengujian pada Log Viewer atau laporan eksekusi.

## 5. Hasil Pengujian
Berdasarkan eksekusi Test Suite pada 24 Oktober 2026:
- Total test case: 10
- Passed: 10
- Failed: 0
- Error: 0

## 6. Struktur Proyek
- Test Cases: berisi 10 test case pengujian.
- Test Suites: berisi Test Suite untuk menjalankan pengujian.
- Object Repository: berisi objek elemen website yang digunakan oleh test case.
- Reports: berisi laporan hasil eksekusi jika tersimpan oleh Katalon.
